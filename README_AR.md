# تحديث الصلاحيات والواجهات — حلقات مشكاة ونور

هذه الحزمة **لا تحذف أي ميزة أو ملف من المشروع**. هي تضيف طبقة صلاحيات وواجهات فوق النسخة الحالية داخل مجلد `Mishkat Noor Halaqat`، وتنسخ احتياطياً كل ملف يتم لمسه قبل التعديل.

## ما الذي تضيفه؟

- واجهات ومسارات مستقلة: المدير العام، مشرف الفرع، المعلم، ولي الأمر، الطالب.
- منع فتح Dashboard لدور آخر من السيرفر (403) وليس إخفاء القوائم فقط.
- استمرار نطاق البيانات الموجود في النظام، مع تشديد قائمة ولي الأمر/الطالب لتعرض الملفات المرتبطة بالحساب فقط.
- لوحة كاملة للمدير لإضافة وإصدار الحسابات، تعديل الاسم وUsername، تفعيل/تعطيل الحساب، وإصدار رمز مؤقت.
- منع Username المكرر من السيرفر وقاعدة البيانات الحالية.
- قوائم أسماء للحلقات والطلاب والمعلمين مع بحث داخل القوائم.
- مسار موافقات للتعديلات الكبيرة التي يرفعها المشرف: نقل طالب، تعديل حلقة، تغيير معلمي حلقة، تعطيل حساب. لا ينفذ التعديل إلا بعد موافقة المدير.
- عرض قبل/بعد، سبب الطلب، مقدم الطلب والمراجع.
- سجل عمليات للمدير العام.
- تصميم متجاوب إضافي مع الحفاظ على الواجهة والمزايا الموجودة.

## التطبيق

1. احتفظ بنسخة المشروع الحالية.
2. فك ضغط هذه الحزمة.
3. شغّل:

```bat
APPLY_UPDATE.bat "C:\المسار\إلى\Mishkat Noor Halaqat"
```

أو:

```bash
python APPLY_UPDATE.py "/path/to/Mishkat Noor Halaqat"
```

سيُنشأ داخل المشروع مجلد احتياطي باسم يبدأ بـ `_backup_before_role_update_`.

## الاختبار

من داخل مجلد المشروع:

```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt
python -m pytest -q
```

ثم شغّل المشروع بالطريقة المعتادة (`START_LOCAL.bat` على ويندوز) واختبر تسجيل الدخول بكل دور.

## ملاحظة قاعدة البيانات

تمت إضافة جدول واحد فقط لطلبات التعديلات (`halaqa_change_requests`). المشروع يستخدم `Base.metadata.create_all(...)` عند التشغيل، لذلك يُنشأ الجدول بصورة إضافية دون حذف الجداول أو البيانات الحالية.
