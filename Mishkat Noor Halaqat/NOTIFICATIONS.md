# تفعيل الإشعارات الحقيقية والبريد

الإرسال فعلي عبر Web Push وSMTP، وليس تنبيهًا داخل الصفحة فقط. مفاتيح VAPID تنشأ مرة واحدة وتحفظ في قاعدة البيانات الحالية. لا تحذف جدول push_keys أو تبدل القاعدة لأن الأجهزة المشتركة تعتمد هذه المفاتيح.

على Render يعمل عامل الإرسال داخل التطبيق تلقائيًا عندما APP_ENV=production. يمكن ضبط NOTIFICATION_WORKER=1 صراحة (ومحليًا للاختبار). استخدم عامل Uvicorn واحدًا كما في Dockerfile. دون العامل تبقى الرسائل في قائمة الانتظار. يفضل ضبط VAPID_SUBJECT بقيمة mailto: ثم بريد تواصل تملكه؛ الافتراضي رابط خدمة Render.

## الآيفون وiPad
1. iOS/iPadOS 16.4 فأحدث: افتح الرابط في Safari وأضفه للشاشة الرئيسية.
2. افتحه من الأيقونة وسجل الدخول.
3. افتح «إشعارات الجوال والبريد»، ثم «تفعيل إشعارات هذا الجهاز»، واسمح بها.
4. جرّب «إرسال تنبيه تجريبي» والجوال مقفل أيضًا، وتحقق من إعدادات التركيز والإشعارات.

على Chrome/Android وFirefox المدعومين فعّل الاشتراك من الإعدادات نفسها. يلزم HTTPS (localhost متاح للتطوير). لا يلزم بقاء الصفحة مفتوحة لوصول Web Push، لكن يلزم اتصال الجهاز بالإنترنت وإذنه وخدمة إرسال متاحة. مجرد حفظ الموقع على الشاشة لا يمنحه إذن التنبيهات.

## البريد
أضف إلى Environment لنفس خدمة التطبيق الحالية:

| المتغير | القيمة |
|---|---|
| SMTP_HOST | خادم مزود البريد |
| SMTP_PORT | 587 لـ STARTTLS أو 465 لـ SSL |
| SMTP_SECURITY | starttls أو ssl |
| SMTP_USER | اسم مستخدم الإرسال |
| SMTP_PASSWORD | كلمة مرور التطبيق/الإرسال |
| SMTP_FROM | عنوان مرسل موثق لدى المزود |
| PUBLIC_URL | https://mishkat-halaqat-v88.onrender.com أو نطاق الخدمة الحالي |

إن لم يحدد PUBLIC_URL يستخدم RENDER_EXTERNAL_URL. لا تستخدم رابط لوحة Render. قد يطلب مزود البريد توثيق عنوان المرسل/النطاق، وتطبق رسومه وحدوده. لا توجد أسرار أو خدمة بريد مفعلة مسبقًا ضمن الملف.

بعد حفظ المتغيرات وإعادة نشر نفس الخدمة: يضيف المستخدم بريده ويطلب رمزًا ويؤكده. صلاحية الرمز 15 دقيقة، بخمس محاولات ودقيقتين بين طلبات الرموز. لا ترسل تحديثات الطلاب لبريد غير موثق. تغيير البريد يوقف الإرسال حتى توثيق العنوان الجديد.

## التسليم والخصوصية
التحديثات تشمل الحضور والتقييم والأوراد والشهادات والمراسلات والاختبارات عند حفظها. يختار المستخدم الأنواع ويوقف القنوات. مستلم التقارير الحالي فقط يصله تنبيه الطالب، مع إعادة فحص الصلاحية قبل الإرسال. رسائل الأسرة واعتذاراتها تنبه فريق الحلقة المخول كذلك. نص شاشة القفل عام ولا يحتوي أسماء أو هوية أو درجات؛ التفاصيل بعد الدخول.

«سُلّم لمزوّد الإرسال» يعني قبول خدمة Push/SMTP، وليس إثبات العرض أو القراءة. توجد خمس محاولات بتأخير متزايد، وتلغى الاشتراكات المنتهية. قد يتكرر بريد في الحالة النادرة لتوقف الخادم بعد إرسال البريد وقبل حفظ نتيجة التسليم. يمكن الإيقاف من إعدادات المستخدم.

لم نختبر التسليم الحقيقي لجهازك أو بريدك دون إعداد مزودك والنشر؛ استخدم زر التجربة بعد التحديث. اختبار النقل المحلي يستخدم مزودًا بديلًا للاختبار ولا يرسل للآخرين.
